# Комплект визуальных референсов · v1.0 / частичная приёмка

## Результат

Создана независимая галерея 78 поверхностей на 69 шаблонах: публичные страницы,
клиника, поставщик, оператор, доступ, системные состояния и четыре листа
компонентов. Для каждого пункта есть полноразмерный HTML-референс и интерактивный
просмотр. Формы/таблицы используют общие helper-функции, header и CSS.

Два AI-концепта: документолог и раскрытые формы/списки/подсказки. Они созданы
встроенной генерацией по прикреплённым локальным эталонам; prompts сохранены
в `concepts/PROMPT.txt` и `concepts/ATLAS_PROMPT.txt`. CLI/API fallback не использован.

Это не полностью принятый production UI. Владелец утвердил только направление
четырёх исходных изображений. Новые экраны, тексты, состояния и числовые токены
имеют статус PROPOSED.

## Что сохранено из эталонов

- Светлый спокойный фон, тёмный графит, глубокий зелёный акцент.
- Выразительные заголовки, тонкие границы, небольшие радиусы и плотные данные.
- Одна верхняя навигация вместо глобального sidebar.
- Цена за одинаковую упаковку; различие товара и предложения.
- Явные изменения цены/остатка, отдельное действие пользователя для количества.
- Отдельные состояния заказа, оплаты, формирования и подписания документа.

Нормализованы высота/состав header (база — оригинал карточки товара), название
валюты, поведение таблиц и полей. «B · Quiet Editorial» не перенесено в интерфейс.
Левые фильтры каталога разрешены последним запросом как локальный инструмент;
противоречие со старым требованием горизонтальных фильтров отмечено, рабочий UI
не менялся. Manrope взят из существующей сборки; шрифт в исходных PNG не объявлен
точно распознанным.

- Статическая структура: попытка 1 обнаружила по два h1 на трёх публичных
  страницах. Убрана лишняя общая title-row для hero. Попытка 2: 78/78 PASS.

  на 390/768/1024/1536 PASS по горизонтальной геометрии.
- PNG: исходный screenshot/fullPage, точный CDP clip, гипотеза компенсации
  масштаба. Три попытки не дали надёжного pixel-exact результата. Экспорт
  остановлен; ещё один браузер/сессия не использовались для сброса лимита.
- Прямое открытие локального PNG через file URL заблокировано браузером.
  Повторного открытия этого ресурса и обхода запрета нет. Сервер прототипа
  запрещает каталоги originals/concepts; картинки доступны пользователю как
  локальные артефакты и уже показаны в чате генерацией/просмотром изображения.

## Ограничения комплекта

1. Не подготовлен проверенный набор PNG всех страниц. Основной формат — HTML.
   `screens/` и `evidence/capture-scale-probe.png` содержат диагностические снимки,
   не утверждённые эталоны. Они не используются в превью галереи.
2. Состояния loading/empty/error/no-access даны общими шаблонами. Конкретные
   сообщения каждого настоящего API и каждое поле не приняты отдельно.
3. Некоторым действиям прототип отвечает честным пояснением, а не имитирует
   успешную бизнес-операцию. API, БД, localStorage и внешние отправки не используются.
4. Полноценные combobox keyboard semantics, nested popup, draggable drawer,
   screen reader, zoom/экранная клавиатура и все touch-варианты не проверены.
5. Товарные фотографии в новых HTML-примерах заменены явно подписанными
   placeholders; четыре исходных товарных эталона сохранены. Это не утверждение
   замены фото в конечном продукте.
6. Юридические страницы показывают структуру, не новый юридический текст.
   Счёт 55 950 ₸ — тестовый, не платёжный документ и не подписанный оригинал.
7. Синтетический DM-0264 показан в двух временных срезах: подтверждение количества
   до отправки решения и уже подтверждённый заказ/счёт. Это не два одновременно
   действующих состояния одного заказа. Полная сверка демонстрационного dataset
   всех дополнительных экранов остаётся отдельным пунктом перед утверждением.

## Решения владельца

1. Утвердить нормализованный общий header и выбранные точные токены.
2. Решить исключение для авторизации: компактная шапка или текущая общая.
   Пока показана общая; компактный вариант не принят молча.
3. Утвердить поведение таблиц как вертикальных строк на mobile и локальную
   прокрутку PDF; точную плотность и размеры touch-целей.
4. Определить финальные поля/ответственность в CORE-02, полный состав account/team
   и billing. Внешние платежи, ЭЦП, 1С и доставка не объявлены подключёнными.
5. Принять основной HTML-формат или отдельно разрешить следующий ограниченный
   этап восстановления точного PNG-экспорта после установленного лимита.

## Безопасное внедрение после утверждения

Сначала сверить существующий `packages/ui`, затем перенести только утверждённые
tokens и header. Далее по одному сценарию: каталог/карточка/корзина → заказы и
документы клиники → предложения/импорт/исполнение поставщика → оператор →
дополнительные модули. Сохранять API, деньги, tenant context и статусы; нет
основания переписывать backend ради этого дизайна. Проверки — по Workflow и риску
каждого change set, а не все команды после каждого макета.

Пересекающиеся UI standards уже меняются в основном потоке. Вместо перезаписи
создано `STANDARD_AMENDMENT_PROPOSAL.md`. Engineering-чекбоксы, код приложений,
зависимости, БД и Git state не изменены этой задачей; commit/push не выполнялись.
Общая production-приёмка не закрывается.
