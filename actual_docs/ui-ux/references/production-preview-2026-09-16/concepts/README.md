# AI concept: документолог

`buyer-documents-ai.png` создан imagegen с двумя приложенными исходными эталонами: карточка товара (геометрия header) и заказ поставщика (таблицы/действия). Оригинал генерации сохранён без изменения.

Визуально осмотрен: читаемые строки, единая тёмно-зелёная палитра, аккуратная иерархия, нет глобального sidebar. Это PROPOSED, не согласованный экран и не runtime evidence.

Намеренные отличия воспроизводимого прототипа: статичные help icons у полей, одинаковая геометрия header, точные текстовые данные, отдельные состояния. Количество «12 документов» в концепции иллюстративное; прототип использует четыре видимые синтетические записи и не выдаёт несуществующие восемь за доступные документы. Сумма счёта 55 950 ₸ не означает подтверждённую оплату. Инвойс и квитанция — тестовые, юридическое подписание не показано.

Изображение не доказывает работу фильтров, подписания, скачивания, tenant isolation или оплаты.

## AI-лист компонентов

`components-overlays-ai.png`: второй отдельный вызов встроенного imagegen по
оригинальной карточке и созданному документологу. Prompt: `ATLAS_PROMPT.txt`.
Лист фактически осмотрен: все четыре компонента раскрыты, читаемые labels,
единый header, спокойная светлая палитра. Статус PROPOSED.

Не копировать буквально сокращённое «Выйти» в опасном действии — в спецификации
и HTML используется «Выйти без сохранения». Показанный неподдерживаемый файл
иллюстрирует ошибку, а не устанавливает новый whitelist MIME-типов. Не использовать
изображение для оценки точного контраста, геометрии и keyboard behavior.
