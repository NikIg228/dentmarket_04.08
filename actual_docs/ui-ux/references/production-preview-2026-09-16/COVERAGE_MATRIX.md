## Состояния и повторное использование

- Loading / empty / error / no-access / expired session / 404: отдельные `system-*` референсы.
- Validation / partial result / price-stock conflict / disabled action / upload error: `components-feedback`, `components-controls`, `buyer-cart`, `supplier-import-review`.
- Open modal / combobox / popover / unsaved changes: `components-overlays`.
- Native select и базовые поля интерактивны; сложные keyboard/nested-popup контракты ещё не приняты.
- Публичный статичный юридический текст: некоторые async состояния N/A; реальное содержание берётся из утверждённой редакции.
